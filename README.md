
# FoodHub Order & Delivery Analysis Dashboard

## 📌 Project Overview
An end-to-end business intelligence project analyzing FoodHub's food delivery operations — covering 1,898 orders, 1,200 customers, and $31.31K in revenue using Python, SQL & Power BI

## 🎯 Objectives
- Identify top-performing restaurants and cuisine types by revenue
- Analyze customer order patterns across weekdays vs weekends
- Understand delivery time distribution and its impact on ratings
- Provide data-driven business recommendations

## 📊 Key Insights
| Insight | Finding |
|---|---|
| Top Restaurant | Shake Shack — $3.6K revenue |
| Most Ordered Cuisine | American — 584 orders |
| Peak Period | Weekends (1.4K orders vs 0.5K weekdays) |
| Avg Delivery Time | 24.16 minutes |
| Highest Rated Cuisine | Spanish — 4.6 avg rating |
| Revenue Leaders | American (30.44%) + Japanese (24.47%) = 55% |

## 🛠️ Tools & Technologies
- Python - Used for Data Cleaning
- **SQL** — 20+ queries for data extraction and analysis
- **Power BI** — Interactive dashboard with slicers, filters, DAX measures

## 💡 Business Recommendations
1. **Weekend staffing** — Scale delivery personnel on weekends to handle 3x demand
2. **Promote Japanese cuisine** — Strong revenue share (24.47%) with growth potential
3. **Delivery optimization** — Target sub-20 min delivery for higher ratings
